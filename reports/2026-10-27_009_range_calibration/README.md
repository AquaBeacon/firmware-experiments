# 算出距離・既知距離補正・マルチパスRAM検証

## 前提
- ユーザー実測の振動子間距離10cm。コンソールから校正したいとの指示。
- Pico 2 W / Arduino-Pico / PlatformIO。PCのWi-Fi切替なし。親機内蔵Webの実機操作はユーザーが行う。
- 親子USB番号とP_MAIN/C_MAIN応答を照合して停止後に書込み。SDフォーマット・既存ログ削除・既存校正削除なし。

## 実施
- 最新RESULTを別途保持し、実験画面・状態画面・ゲイン確認で補正前/後の距離、受信時刻差、結果番号、経過時間を確認可能にした。
- Webに10cm等の既知距離と音速入力、固定配置確認、31件取得、補正候補の確認・保存/適用・中止・無効化を追加。1点の固定遅延補正であり、音速自体は求めない。
- 周波数・パターンの一致時のみ補正を適用。欠損/取得異常/ばらつき/期限外の候補を拒否。保存は新規ファイルへsync・読戻し・CRC・renameで確定し、以前の値を維持する。
- 子機のDMAリングは16384×uint16_t=32768byteで固定。3秒120000byte、5秒200000byteはSDへ逐次保存。ゲイン確認と排他共有し、秒数に比例するRAM確保はない。リング猶予0.8192秒を超える処理停止は欠損となる。
- writeBinaryの2112byteとmultipathTickの2060byteをコア0専用の固定領域へ移し、入れ子のスタック使用を減らした。再帰や他コアからの呼出しはない。
- 親機Health/Rangeへkind15を追加し、生ToF・適用補正番号・音速・補正前/後距離を追跡できるようにした。

## ソフトウェア検証
- scripts/test_host.py全体PASS。既知距離計算、外れ値、ばらつき、CRC、設定変更/欠損/期限超過、実ストレージ処理の書込み/sync/rename失敗、破損検出、実UI関数の距離保持/無効表示/10cm入力を検証。
- parent/child100ビルドSUCCESS。最終ビルドの静的RAMは親機394812/524288byte、子機278756/524288byte。これはヒープ・スタックの実使用を合算した値ではない。
- nmでmonitorBuffer=32768、writeBinary buffer=2112、multipath block=2060byteを確認。

## 実測
- USB P_MAIN A444A41EE9334705/COM6、C_MAIN A521D21EB1DCFB44/COM3を応答と照合。両機へ書込み・フラッシュ照合成功。
- 10cm校正：31件有効取得、無効1件。中央値3us、MAD1us、外れ値除外後30件。固定補正−63.667usを親機SDへ保存・読戻し・適用（保存番号1）。補正前中央値0.0045m、補正後0.1000m。
- 同じ10cm位置で保存後の別測距を実施。状態照会で重複を除いた4結果は0.0985〜0.1045m、中央値0.09925m。これは状態照会で確認できた部分集合で、全送信の誤差分布・別距離精度ではない。時刻差3usを正しい音響到達と独立に検証したわけではない。
- RAM：子機の実測heap_free最小216048byte、親機87408byte。マルチパス稼働中も子機の空きヒープを維持。静的領域は子機278752byte、主リング32768byte。全5秒分200000byteをRAMに保持しない構造をコード・ELFと実機で照合。
- 観測SDファイル855843byte、1303レコードをUSB jで読出し、全CRC PASS。ADCエラービット0、比較器エッジ・要求キューの欠損0。

- 対策として通常IMU/BNOログ・エッジ書込みを経過時間で区切り、観測中のSD同期を観測終了後へ延期。SDの単一書込みが0.8192秒を超えないことを保証する変更ではない。
- 対策版を親子へ書込み。再試験時、親機のcardBeginは完了するがvolumeBegin（ファイルシステム初期化）内でUSB/コア0が進まない症状を確認。コア1の起動段階診断でstage112を継続確認した。原因をFS破損とは断定しない。USB再書込みでSD電源は切れないため、ユーザーに電源入れ直しを依頼中。
- 最初の試験終了時は親子測距停止・SD STOPPEDを確認。対策版の観測再試験・保存値の再起動復元は電源入れ直し後に続ける。


## 未検証
- Web画面の実機操作、別距離での絶対精度、温度/塩分/配置/ゲイン変更後の妥当性。10cmで合わせた結果が10cmになることは独立した精度検証ではない。
- ヒープ空きと静的RAMから、スタックの最大使用量・断片化・長期運転余裕まで保証しない。

## 実機操作の手順
1. 親機SDの初期化が完了した状態で「実験・測距」を開く。算出距離欄で最後の結果と経過時間を確認できる。
2. 「既知距離で測距を校正」を開き、振動子間の既知距離10cmと使用する音速を入力し、固定配置の確認にチェックを入れる。先に通常の測距送信を停止する。
3. 「既知距離の測定を開始」で31件を待つ。無効件数・中央値・中央値からの偏差・固定補正を確認し、「補正を親機SDへ保存・適用」を押す。
4. 同じ周波数・パターンで測距を開始し、補正前と補正後を確認する。別の既知距離でも検証する。配置・ゲイン・振動子・水条件が変わったら補正を無効にして再校正する。
5. 観測ログは `scripts/verify_multipath_log.py` でCRC・欠損・ADCエラービットを確認できる。COMPLETEは処理終了を表し、欠損なしとは別に判定する。
