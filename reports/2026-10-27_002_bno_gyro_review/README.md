# 子機BNO085のジャイロ校正条件の確認・修正

## 前提

- 2026-10-27 JST。当初はユーザーが親機・子機未接続と明示したためPC上のみで調査・修正した。その後、ユーザーが修正用に子機を接続したと通知したため、子機の識別・安全停止・書込み・読取り確認を追加した。PCのWi-Fi切替、SDフォーマット、既存ログ削除、校正開始・保存操作は行わない。
- AquaBeacon_MAIN_firmwareの作業ソースを確認。比較元は直前の公開ソースbdc291b（P_MAIN_experiment/firmware/main_control）。本修正は作業ソースと接続された子機へ反映。GitHub/Pagesと親機は未反映。
- GP6/PPS、GP7–D03半二重、D02入力専用を含むピン・通信配線は変更しない。親機温度・水圧・LCDは対象外。

## 確認した問題

1. 従来は全3種の最新状態が同時に2以上で5秒続かないと保存できなかった。ジャイロが低(1)の間は、どれだけ台上で静止しても保存できない。これはアプリが追加した条件で、メーカー手順の要求ではない。
2. 校正開始マスクは加速度+磁気の0x05。さらに同梱SH-2のConfigure ME処理はP5を送らず0固定、Get ME処理もR5を捨てるため、台上校正を有効化・復元できなかった。台上校正がジャイロ待ちの実機原因だったかは未接続のため断定しない。
3. CEVA手順は加速度の4〜6姿勢、ジャイロの台上静止約2〜3秒、その後の磁気回転と磁気状態2/3を案内する。静止と回転を同時に要求しない。手持ちジャイロ動的校正と台上校正は別設定である。

## 修正

- SH-2にSH2_CAL_ON_TABLE=0x10、P5送信・R5読戻しを追加。校正中は0x15（加速度+磁気+台上）、終了・タイムアウト時は開始前の実設定を復元する。手持ちジャイロ動的校正は有効にしない。
- 加速度・磁気は最新の中(2)以上を維持。ジャイロは最新の中(2)以上、または低(1)かつ今回3秒の静止確認がある場合に保存条件へ進む。全条件の継続確認は1秒へ変更。
- 静止確認の目安は角速度ベクトルの大きさ0.05rad/s以下が連続3秒。水平は不要。後続の磁気回転では確認済みを保持する。500ms以上の取得間隔、未校正(0)、非有限値、セッション再開始/BNOリセットで確認を無効にする。保存時には全3種の新しい値が必要。
- この静止確認はアプリ側の動きの目安であり、CEVA内部の校正成立や実測精度の認定ではない。低(1)は低のまま画面表示し、その状態で保存可能になる場合も精度未検証と表示する。
- 状態JSONへgs（静止確認0〜3000ms）/gr（確認済み0/1）を追加。旧子機では旧条件の案内を維持し、ブラウザだけで保存許可を変更しない。新条件の使用には親子両方の更新が必要。

## 実施・結果

- 直前の公開ソースをコンパイルして再現：ジャイロ低の状態を10秒継続してもready=false、全3種中以上でも3秒ではfalse。実際のSH-2送信関数もP5=0で、R5が設定復元に残らないことを確認した。模擬データであり実機測定ではない。
- 修正版ホストテスト終了コード0、PASS表示44件。実際の校正ハンドラの静止後保存・保存失敗・終了失敗/再試行・タイムアウト、SH-2のP5/R5送受信と復元、静止→磁気回転、ジャイロ低/0/古い値/欠測/非有限値、セッション変更、64bit時刻、画面の進捗・旧版案内を確認。
- Pico parent / child100ビルドは両方SUCCESS。Spresenseソース変更なし。
- 子機USB A521D21EB1DCFB44 / COM3とC_MAIN応答を照合。記録停止を確認し、child100をアップロード。フラッシュ100%照合・再起動成功。
- 再起動後も同じUSB番号とC_MAIN、BNO_STAGE=3を確認。約12秒の読取りで子機SD保存行数2228→3345、IMUサンプル2733→3854。SDエラー0、IMUイベント欠落0、sd_reason=NONE。記録は継続する。
- 読取り期間の親子相対同期は成立。テザーエラー累計は1→1で、0ではないが観測期間内の増加なし。累計1の原因と同期の実測精度は今回未検証。
- 親機USBは未検出で親機更新はしていない。テザー応答はあるが親機のUSB経由の個体・役割照合は今回未実施。新しい静止進捗表示は親機更新後に使用する。
- 実行出力・USB状態の生ログはreports/raw/2026-10-27_002_bno_gyro_reviewへ保存。公開可能な結果要約と書込みバイナリのハッシュはevidence/verification.json。

## 未検証と実機での確認手順

実機の状態推移、台上設定への実機応答、保存後の電源再投入による保持、実測角度・ドリフト・温度依存、静止目安の実環境での適否は未検証。子機書込みと起動・記録確認まで実施。

親機の再接続後、USB個体番号と役割を照合して親機を更新する。子機は更新済み。測距と子機記録を停止して校正を開始し、姿勢変更→手を離して台上約3秒→各軸の磁気回転の順に操作する。静止表示の増加、磁気回転中の確認保持、低状態が低のまま表示されること、保存応答と再起動後の保持を確認する。ジャイロ0・通信失効・不正値では保存できないことも確認する。実機精度は別途測定する。
