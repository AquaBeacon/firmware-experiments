# 子機の機体軸合わせ後のSD確認

## 前提
- ユーザーから子機の機体軸合わせ実行とSD挿入の連絡を受け、PCのD:（FAT32、リムーバブル）を読取り確認。
- 収録内の機体ID A521D21EB1DCFB44、role=2により子機データと確認。USB接続・書込みは実施していない。
- SDの書込み・削除・フォーマット、PCのWi-Fi切替、実機Web操作、ファームウェア変更なし。

## 実施
- BODY_CAPTURE 2件、最新BNO校正保存履歴、最新収録が参照するIMU/BNOイベント/HEALTHログをPCのreports/raw/2026-10-27_019_child_body_sd_checkへコピー。全6ファイルのSHA256をSD原本と照合し一致。
- 既存のbinary_log/decode_binaryで全レコードのCRCと末尾、body_alignmentで収録完了・校正参照・起動一致・静止・姿勢整合性を検査。
- 不合格理由の切り分けとして各静止区間の平均・標準偏差と、平均値を使ったIMU姿勢/磁気の整合性を独立に診断。受入条件の緩和やデータの選別による軸結果の生成は行っていない。

## 実測
- 最新C_MAIN_BODY_CAPTURE_00002.binはcapture=2、boot=1606829173、IMU/磁気校正参照=4。完了イベント4、mask=31、12マーカー、CRCエラー0、末尾欠損なし。
- 対応ログはC_MAIN_IMU_100Hz_29174.bin、C_MAIN_BNO_EVENTS_29174.bin、C_MAIN_HEALTH_RANGE_29174.bin。全て同じ起動session。
- IMU 17,921件、BNOイベント62,748件、HEALTH 177件を全件読取り。CRCエラー0、末尾欠損なし。IMU index不連続0、scheduled_usの10msグリッド欠落0。これは全BNOセンサーのイベント連番無欠落を認定するものではない。
- 区間1〜5の開始/終了dropsは全て262で増加0。累積262は収録開始前から存在しており、起動全体の取りこぼし0とはしない。
- BNO校正履歴C_MAIN_BNO_CAL_00004.binは112byteの独立Profile形式（AQBINログ形式ではない）。magic/version/size、CRC、generation=4と機体IDの一致を確認。内部DCD係数の読出し一致までは確認していない。
- C_MAIN_BODY_ALIGN_*.binはカード上に存在せず、軸変換の保存は未実施。
- 旧C_MAIN_BODY_CAPTURE_00001.binは区間5の中止イベント5、mask=15。最新収録の代わりには使用しない。

既存解析と同じく区間開始後1秒、終了前0.25秒を除いたfreshサンプルで算出。標準偏差は3軸の最大値。加速度のゲートは0.04m/s²以下、ジャイロは0.003rad/s以下。

- 正規の軸解析は区間2のAcceleration unstable during poseで停止。インポート用child_axes.jsonは生成していない。
- 静止ゲートとは別の診断として、4姿勢平均の重力方向から算出した整合誤差は0.00 / 2.12 / 1.24 / 9.59度。区間4が5度ゲートを超える。これは実姿勢精度の測定値ではない。
- 平均磁場の大きさは区間順に34.60 / 51.60 / 33.85 / 42.62（記録の磁気単位）。既存magnetic_fitはMagnetic field magnitude inconsistentで拒否。周囲の金属・磁石・電子機器や位置移動などの寄与、個別磁気補正の妥当性はこのデータだけでは確定できない。
- 区間5は35.029秒で終了。解析用の端を除いたfreshジャイロ3,210件、時間幅33.769秒。既存--movement-onlyでchild_camera_capture.jsonとchild_movement.csvをPC側へ生成。軸合わせ不合格とは独立した動作データの抽出であり、カメラ時刻照合の成功を意味しない。

## 判定・次の実施
- 収録操作の全区間完了と、今回参照ログの保存整合性は確認。機体軸合わせは解析不合格のため未完了。
- 次回は同じ場所・同じ世界基準方向を保ち、各姿勢を台や非磁性の支持具で安定させ、静止してから区間開始、区間終了後に持ち替える。区間4は基準へ一度戻してから機尾だけを上へ90度にする。
- 磁石・鉄製机・工具等から離して再収録。今回の結果だけでBNOの個別校正をやり直す必要があるとは断定しない。
- 現行手順では新しいBODY_CAPTUREで区間1〜5をまとめて再収録する。既存データは保持する。
